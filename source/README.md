# v0.6710a source snapshot

This folder contains the complete C++ source tree, regression tests, and x86 build script corresponding to the release DLL at the package root. Third-party notices are in `../THIRD_PARTY_NOTICES.txt`.

Build with Visual Studio 2022 Community's x86 C++ toolchain by running `build_x86.bat` from this directory. The build writes outputs to `source/bin`; no built object files are included.
